# Contributing to Chess Air

Thank you for your interest in contributing to Chess Air! We welcome contributions to improve chess engine interactions, real-time multiplayer synchronization, and UI styling.

## Getting Started

1. Fork the repository and clone it locally:
   ```bash
   git clone https://github.com/hrgang-hrushi/chess-air.git
   cd chess-air
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Development Workflow

- Create a descriptive branch: `git checkout -b feat/your-feature-name`
- Test multiplayer features by opening two separate browser windows (or one incognito window) at `http://localhost:5173`.
- Ensure clean builds: `npm run build`
- Submit a Pull Request targeting `main`.

## Code of Conduct

Please maintain a friendly, welcoming, and constructive environment for all contributors.
